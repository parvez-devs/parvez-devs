# TaskFlow

A polished, responsive to-do list application built with vanilla HTML, CSS, and JavaScript. Tasks persist automatically in the browser's `localStorage`.

## Features

- Add, complete, and delete tasks
- Filter all, active, or completed tasks
- Clear completed tasks
- Persistent local storage
- Responsive and accessible interface
- No dependencies or build step

## Run locally

Open `index.html` directly, or run `npx serve .` in this folder.
